# Security threat model

| Threat                                 | Control                                                                                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fake model-authored tool result        | Only Rust host functions create `host_result`; model continuation is never trusted.                                                                     |
| Prompt injection in files/tool output  | Content is data framed outside the host instructions; it cannot alter permissions, the offered tools, or the constitution (ADR-0022).                   |
| Arbitrary file read                    | Opaque attachment grants, type allowlist, regular-file check, and 1 MiB cap.                                                                            |
| Shell injection                        | No shell command is exposed in default capabilities; GGUF import uses a fixed executable with separate validated arguments.                             |
| Secrets in logs/export                 | Credentials never enter normal UI state, logs, or exports.                                                                                              |
| Dangerous Markdown                     | Renderer escapes all text and only creates controlled links with `target`/`rel`.                                                                        |
| Unbounded tool loop/payload            | Four generations with tools run in the first three, eight calls per round, and 64 KiB argument/result budget.                                           |
| Local/remote confusion                 | Locality is a typed profile property, shown on the model pill, in the model picker, in chat details, in Models, and in Settings › Privacy & data.       |
| Malformed assistant import             | Versioned schema validation and inert JSON parsing.                                                                                                     |
| Database corruption                    | SQLite migrations, foreign-key enforcement, and normalized entities.                                                                                    |
| Untrusted model download               | Catalog entries are checked in, HTTPS-only, size-bounded, and SHA-256 verified before atomic installation.                                              |
| Substituted imported model             | Imports must match the catalog's size and SHA-256; the installed bytes are what is hashed; a qualified profile binds to one artifact hash.              |
| Unqualified runtime for a profile      | `--version` before load and `/props` after load must match the profile's build, served template hash, and context; no CPU or remote fallback.           |
| Path traversal or symlink escape       | Managed paths derive only from safe catalog variant IDs; symlinks are rejected for verification and resume.                                             |
| Local runtime network exposure         | Loopback-only port, per-launch API key from an owner-only file deleted after startup, web UI and slot endpoints off, `--offline`; no LAN bind.          |
| Resident runtime left running          | One server, stopped on exit and on unload; switching models waits for in-flight generations; a crashed server is restarted, not reused.                 |
| Model-written memory                   | `memory.save`/`memory.delete` need per-call approval of the exact text shown by the host; standing grants never cover them; private chats get none.     |
| Raw reasoning disclosure               | Analysis is never emitted to the webview, never persisted (dropped on native save and on load), and never re-sent.                                      |
| Fabricated links and citations         | Links are inert; answers with model-written URLs, DOIs, or arXiv IDs are marked as not checked.                                                         |
| Forged tool history from the webview   | Requests may not contain `tool` messages or non-leading `system` messages.                                                                              |
| Chat-template tokens in untrusted text | `<                                                                                                                                                      | name | >` sequences in profiles, history, memories, attachments, tool results, and returned arguments get a word joiner, so llama-server cannot parse them as turns. |
| Webview-declared tool risk             | The host assigns each tool's risk by name (`tools::host_risk`); tools the host does not implement are never offered.                                    |
| Port taken before the server binds     | `/props` needs the per-launch key and must report the model path Juniper passed; otherwise the start fails.                                             |
| Juniper killed while a model is loaded | A server still loading is reachable from exit cleanup; on Linux the server also receives SIGTERM when Juniper dies.                                     |
| Imported file changed after import     | A hard-linked import shares bytes with the user's file; a size or modification-time change triggers a full rehash; a change during hashing is rejected. |

## Agent (Beta), web, plugins, and transfers

These rows cover capabilities added on the "Fixing Up A Little" branch (ADRs 0025–0028).

| Threat                                                                        | Control                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Prompt injection from pages, files, skills, plugin output, or subtask reports | All of it is framed as untrusted data; host instructions say so; nothing in it can change the offered tools, risk, grants, or the goal. A poisoned plugin result in the runner test leaves grants unchanged.                                                                                                                                                   |
| Confused deputy (model chooses a dangerous tool)                              | Tools come from the host registry filtered by the agent profile, project, platform, and role; risk is the host's; writes, network, code, and plugin calls ask unless a scoped grant exists; memory changes always ask.                                                                                                                                         |
| Approval reused for something else                                            | An approval binds to the tool, canonical arguments, and target state (file version, plugin tool-set digest); a change makes it stale and the user is asked again. Unanswered requests expire after 72 hours and never become an allow.                                                                                                                         |
| Grant creep across agents, projects, or servers                               | Grants name the agent and project and, for plugins, the tool-set digest; delegated tasks get parent ∩ role tools; revocation pauses running tasks of that agent.                                                                                                                                                                                               |
| Cross-project leakage                                                         | Tasks see only their project's granted folders and index; the FTS index is filtered by project and live folder grants; revoking a folder deletes its passages.                                                                                                                                                                                                 |
| Folder escape and file races                                                  | cap-std handles, per-component link refusal, size limits, version-bound writes with a re-check before an atomic rename.                                                                                                                                                                                                                                        |
| SSRF and DNS rebinding through web tools                                      | URLs are parsed, local names and private/link-local/metadata/CGNAT/NAT64/6to4-embedded addresses refused; the host resolves names, refuses any non-public answer, pins the vetted address, follows redirects manually and re-vets each hop; no proxies; bounded bytes, time, types; no compressed bodies. Verified live through a public redirect to loopback. |
| Fabricated sources                                                            | Source ids exist only when the host recorded a search result, page, file passage, or plugin result; citations without one are reported as unverified; snippets are labelled as snippets.                                                                                                                                                                       |
| Sandbox escape                                                                | bubblewrap namespaces with no network, read-only system, private work folder, cleared environment, rlimits, wall timeout, and process-group kill; unavailable (and labelled) where not verified.                                                                                                                                                               |
| Malicious MCP server metadata or results                                      | Tool definitions validated (name, object schema, no remote `$ref`, header annotations); invalid tools excluded; descriptions and results neutralized and bounded; no sampling, roots, or elicitation is offered; a changed tool set invalidates standing grants.                                                                                               |
| Credential leakage to plugins or redirects                                    | Plugin and search secrets live in the OS keychain by reference; remote MCP requests do not follow redirects; local servers get a cleared environment plus only the named secrets.                                                                                                                                                                              |
| Ambiguous side effects after a crash                                          | Actions record intent (`started`) before effect; recovery marks them uncertain; resume reconciles file writes by content and reports anything else as unknown instead of repeating it.                                                                                                                                                                         |
| Stale interface snapshot overwriting agent state                              | Agent tables are native-only with revision checks; `save_app_data` cannot reach them (tested).                                                                                                                                                                                                                                                                 |
| Runaway agents                                                                | Step, tool-call, token, time, document, delegation-depth, and child-count budgets; per-cause retry limits; global stop persisted across restart.                                                                                                                                                                                                               |
| Truncated, oversized, or substituted downloads                                | Journal-bound resume, exact Content-Range, Content-Length and checked byte counts, per-file SHA-256 before publish, atomic bundle publish (fixture-tested).                                                                                                                                                                                                    |
| Scheduled automation acting unattended                                        | Runs use current permissions; anything needing approval waits; backlogs are not replayed; retries only when nothing outside Juniper changed.                                                                                                                                                                                                                   |

The verification cache also checks Unix change time. Juniper disables it when a
same-directory probe cannot distinguish rapid change-time updates; unsupported
platforms and directories that cannot hold the probe file rehash on each use.

This document is a v0.3 self-review artifact, not an independent security audit.
